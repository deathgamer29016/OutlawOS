# Contributing to OutlawOS

Thanks for your interest in contributing to OutlawOS.

## Workflow

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Open a pull request

## Rules

- Do not push directly to `main`
- Keep commits clear and readable
- Document major changes
- Do not add telemetry, tracking, or hidden network activity

## Good first contributions

- Documentation improvements
- Installer mockups
- Package/update system design
- UI concepts
- Build scripts

## Compensation

OutlawOS is currently a volunteer open-source project.

Contributors should understand that:

- contributions are voluntary
- contributors are not paid
- there is no guarantee of future payment
- contributors participate because they want to help the project

If the project ever generates funding in the future, compensation models may be discussed.
