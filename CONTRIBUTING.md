# Contributing to OutlawOS

Thanks for your interest in contributing to OutlawOS.

## Workflow

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Open a pull request

## Rules

- Do not push directly to `main`
- Keep commits clear and readable
- Document major changes
- Do not add telemetry, tracking, or hidden network activity

## Good first contributions

- Documentation improvements
- Installer mockups
- Package/update system design
- UI concepts
- Build scripts
