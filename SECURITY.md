# Security Policy

OutlawOS is designed around privacy, transparency, and user control. Security is a core priority of the project.

## Supported Versions

Since the project is still in early development, all current versions are considered experimental.

Security fixes will be released as soon as possible after issues are confirmed.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

When reporting a vulnerability include:

- A clear description of the issue
- Steps required to reproduce it
- The potential impact
- Any proof-of-concept code if available

Please avoid publishing exploit details publicly until a fix is available.

## Scope

Security issues include but are not limited to:

- privilege escalation
- remote code execution
- package verification bypass
- sandbox escapes
- encryption failures
- update mechanism vulnerabilities
- data leakage

## Security Goals

OutlawOS aims to provide:

- minimal telemetry
- transparent system behaviour
- strong encryption
- user control over network activity
- open source verification of all core components
