# OutlawOS

OutlawOS is an open-source operating system focused on privacy, user control, and transparency.

The goal of the project is to create a system where users have full control over their devices, without hidden telemetry, unnecessary data collection, or forced services.

## Core Principles

• Minimal or no telemetry  
• Strong security and privacy defaults  
• Full system transparency through open source code  
• User control over updates, networking, and installed software  
• Clear warnings for suspicious packages

## Planned Features

- Hardened Linux-based system
- Minimal logging
- Optional compatibility layers (Wine / Proton)
- Built-in developer tools and terminal
- Optional privacy tools
- Local update packages with rollback support

## Platforms

Currently targeting:

- Desktop computers
- Laptops

Future plans may include a mobile version.
